\subsection{Exécution des répétitions}

Le protocole multi-graines est lancé depuis la racine du projet avec la
commande suivante :
\begin{verbatim}
.venv/bin/python scripts/08_repeat_experiments.py
\end{verbatim}
Par défaut, le script utilise les graines 42 à 46, les têtes H1 et H2, OBD,
MINT sur H2 et les témoins denses. Il recharge les partitions, les vecteurs
agrégés et W1 depuis \texttt{artifacts/} sans modifier ces fichiers. Les
résultats sont isolés dans \texttt{artifacts/repeated\_runs/}. Une graine
terminée possède son propre sous-répertoire et est ignorée lors d'une reprise ;
l'option \texttt{--rerun-completed} force son recalcul.

Les principaux fichiers produits sont :
\begin{itemize}
    \item \path{metrics_by_seed.csv}, qui conserve les 75 évaluations
    individuelles ainsi que les critères ajustés avec $\alpha=0{,}4$ ;
    \item \path{metrics_summary.csv}, qui fournit la synthèse au format large ;
    \item \path{metrics_summary_long.csv}, qui fournit pour chaque métrique
    l'effectif, la moyenne, l'écart-type, la variance et l'intervalle à
    $95\,\%$ ;
    \item \path{paired_differences_summary.csv}, qui contient les mêmes
    statistiques pour les différences graine par graine entre modèles ;
    \item \path{run_config.json}. Ce fichier enregistre la configuration
    complète et l'activation des contrôles.
\end{itemize}

Chaque sous-répertoire de graine conserve en outre les métriques brutes, la
trajectoire de pruning OBD et les temps de scoring MINT par couche.

\subsection{Exécution du témoin aléatoire}

Le témoin aléatoire est lancé séparément depuis la racine du projet :
\begin{verbatim}
.venv/bin/python scripts/09_random_pruning.py
\end{verbatim}
Le script utilise par défaut les graines 42 à 46 et les têtes H1 et H2. Pour
chaque graine, il reconstruit M1, tire un masque aléatoire, puis applique le
même calendrier itératif et le même budget de réentraînement qu'OBD. Les
résultats sont isolés dans \path{artifacts/random_pruning/}. Ce répertoire
contient les métriques individuelles et agrégées, les différences appariées,
les trajectoires, les historiques d'entraînement, la configuration du run et
les checkpoints RAND-M2/RAND-M3 avec leurs masques. Les graines terminées sont
ignorées lors d'une reprise ; l'option \texttt{--rerun-completed} force leur
recalcul.
